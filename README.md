# nisiarai
nisiarai mobile app for color blind people

## นี่สีอะไร · Color Finder
Static mobile web app: take/upload a photo, drag the + crosshair, see the nearest named color (EN/TH) and Pantone code. Saved colors persist in localStorage. No build step.

Palette: `palette.js` (43 colors). Pantone codes and Thai names are approximate, verify before production.
